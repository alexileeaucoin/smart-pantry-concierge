# My agent: smart-pantry-concierge
One-liner: A conversational agent that helps home cooks track pantry inventory and generate recipe recommendations grounded in available ingredients.

Tool coverage:
- Memory: Remembers dietary preferences, restrictions, and cooking history across sessions
- Tools: Ingredient lookups, recipe searching, and pantry status updates
- Catalog/UI: Collection of pantry items and recipe cards rendered with A2UI
- Image gen: AI-generated preview of finished recipes
- Sandbox: Ingredient unit conversions and recipe scaling calculations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for calculations, Cloud Trace observability
